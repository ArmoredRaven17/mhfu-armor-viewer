      About

      A fan-made viewer for the armor and weapons of Monster Hunter Freedom Unite, with the game's own models, textures and names. Not affiliated with, endorsed by, or supported by Capcom.

      Game content

      Monster Hunter Freedom Unite and all of its models, textures, animations and data tables are © CAPCOM CO., LTD. All rights reserved. Every asset here was extracted from a personally owned copy of the game (the US release) and is shown for reference only.

      What you are looking at

      A basic version. Each armor piece is its own model in the game, worn over the hunter's skeleton; the names and which model each piece draws for each gender come from the game's own tables, and an empty slot shows the clothing the game draws there. The hunter plays the game's own motions, and each weapon sits where the game puts it, sheathed or drawn, worked out by running the game's own weapon code. Weapon classes are the game's own; weapons that share a model are listed together.

      File formats and tables

      • MHFU-ModKit — by sp00ktober Its format documentation (PAC, PMO, TMH, skeleton) is what this app's own converter follows. github.com/MHFU-ModKit/modkit
      • mhff — by Seth VanHeulen Earlier PSP Monster Hunter file-format work that ModKit's model and texture readers build on. github.com/svanheulen/mhff
      • PMO-Importer — by AsteriskAmpersand Its PMO template was a second reference for the model format. github.com/AsteriskAmpersand/PMO-Importer
      • mhfu_transmog — by Exceen Its notes gave the layout of the armor and weapon tables (which model each piece draws). github.com/Exceen/mhfu_transmog
      • FUComplete Its file documentation mapped which game file holds which armor, face and hair model. fucomplete.github.io
      • PPSSPP — Henrik Rydgård and contributors Its source was the reference for the PSP vector unit, so the game's own weapon placement could be run to find where each weapon sits; its save states supplied the game's memory. ppsspp.org

      Tools used to build this

      • three.js Renders the scene, with GLTFLoader, OrbitControls and SkeletonUtils.
      • Pillow, NumPy, pycdlib Read the disc image and the game's archive, and converted the textures during the build.

      Assets

      The theme icons are the MHFU LookUp app's monster icons. The UI textures and the MHFU font are shared with the same author's MHGU fan apps. Armor and weapon names come from the game's own text.
